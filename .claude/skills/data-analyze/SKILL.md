---
name: data-analyze
description: Analyze datasets (CSV, JSON, databases) and report insights. Use for statistics, cleaning, and charts.
---

1. Inspect shape, types, missing values, duplicates, outliers before concluding anything.
2. State the question, then pick the method; show assumptions.
3. Use pandas/SQL; keep the cleaning steps reproducible in a script.
4. Report numbers with sample size and uncertainty; distinguish correlation from causation.
5. Charts: one message per chart, labeled axes, colorblind-safe palette.
