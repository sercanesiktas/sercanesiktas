---
name: project-onboard
description: Get oriented in an unfamiliar repository. Use at the start of work on a new codebase.
---

1. Read README, CONTRIBUTING, CLAUDE.md, and manifest files (package.json, pyproject.toml, go.mod).
2. Map the directory structure and entry points.
3. Find how to install, run, test, and lint; run them once.
4. Check recent `git log` for conventions and active areas.
5. Report a short summary: stack, layout, commands, gotchas. Offer to write CLAUDE.md.
