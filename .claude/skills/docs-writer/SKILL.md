---
name: docs-writer
description: Write README files, guides, API docs, and changelogs. Use when documentation is requested or code changes need docs.
---

- README order: what it is, quick start (copy-pasteable), usage examples, configuration, contributing, license.
- Every command in docs must be one you verified runs.
- Write for the reader's goal, short sentences, concrete examples over abstract description.
- Keep docs next to the code and update them in the same change.
- Changelog: group by Added/Changed/Fixed/Removed, newest first.
