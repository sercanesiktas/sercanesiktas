---
name: code-explain
description: Explain how code or a system works. Use when asked "bu ne yapıyor", "nasıl çalışıyor", or to review unfamiliar code.
---

- Start with the one-sentence purpose, then the data flow, then the details.
- Reference code as `path:line`.
- Trace a concrete example input through the code.
- Distinguish what you verified by reading from what you are inferring.
- Match depth to the asker: short for a quick question, layered for onboarding.
