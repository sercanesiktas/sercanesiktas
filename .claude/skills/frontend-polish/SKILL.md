---
name: frontend-polish
description: Build and refine web UI. Use for layout, responsiveness, accessibility, and visual quality.
---

- Mobile-first; verify at 360px, 768px, 1280px.
- Accessibility: semantic HTML, labels, focus states, keyboard navigation, contrast >= WCAG AA, alt text.
- Support light and dark themes with CSS variables.
- Handle loading, empty, and error states explicitly.
- Check it in a real browser (Playwright screenshot) before calling it done.
- Keep dependencies minimal; avoid layout shift and oversized assets.
