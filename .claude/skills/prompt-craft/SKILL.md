---
name: prompt-craft
description: Write and improve prompts for LLMs. Use when designing system prompts, agents, or prompt libraries.
---

- State role, goal, context, constraints, and output format explicitly.
- Give 1-3 realistic examples, including an edge case.
- Say what to do, not only what to avoid; explain the reason behind rules.
- Separate instructions from data with clear delimiters.
- Test on varied inputs, compare versions, and keep the best; log failures as new test cases.
