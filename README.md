### Hi there 👋

I was born in 1996 in Yalova, Turkey. I started with PHP and MySQL at 14 and have been building things for over a decade since. These days I work mostly with React, Angular, Laravel, PHP, MySQL, MongoDB, JavaScript, TypeScript and Node.js.

### What I'm working on

**[HayalAI](https://github.com/sercanesiktas/hayalai)**: an open prompt library with 17,086 prompts, each with a Turkish description. Search it in the browser, grab the CSV, or plug it into Claude and Cursor.

|---|---|
